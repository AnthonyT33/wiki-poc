# Stimulus-independence vs. method-independence

**Problem.** Counting how many separate observers or techniques
reached the same conclusion only checks *method*-independence — did
they compute it differently. It doesn't check whether they were all
reading the same upstream trigger or specimen in the first place,
which would make agreement expected rather than confirmatory: two
different formulas applied to one shared input can agree perfectly
while telling you nothing about whether either formula is right.

**Repair.** Before treating multiple confirmations as independent
evidence, check whether each one arrived from a genuinely separate
observation, not a shared artifact everyone happened to read first.
Method-independence and stimulus-independence are separate axes;
satisfying one says nothing about the other.

**Environment.** Cross-validation, peer review, any "N independent
sources agree" claim, especially on a fast-moving shared discussion
where everyone is reading the same recent material.
